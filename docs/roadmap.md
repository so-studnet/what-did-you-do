# ロードマップ

小さく作って使いながら改善する、アジャイル型で進める。各マイルストーンが終わった時点で「実際に使える」状態を保つ。

| # | マイルストーン | 内容 | 状態 |
|---|---|---|---|
| M0 | 土台 | Next.js / Tailwind / Vitest / Lint の初期設定、ドキュメント | 完了 |
| M1 | 開始・終了 | 作業の開始、終了、並行実行、経過時間の表示（F1）。保存はひとまず localStorage | 完了 |
| M2 | 保存とログイン | Supabase への保存、ログイン、Vercel へのデプロイ | |
| M3 | 修正 | 記録の編集・後から追加・削除（F3）。ホームの「終了した作業」に日付切り替えを追加 | 完了 |
| M4 | 超過の表示 | 超過の警告表示と超過時間の記録（F2の表示部分） | 一部完了（赤表示・超過時間） |
| M5 | 階層タグ | タグの管理と作業へのタグ付け（F4） | 完了 |
| M6 | テンプレート | テンプレートの管理とワンタップ開始（F5） | 完了 |
| M7 | タイムライン | 1日のタイムライン表示（F6） | |
| M8 | 集計 | タグ別・作業別の集計、超過の振り返り（F7） | |
| M9 | PWA・通知 | ホーム画面への追加、予定時間に達したときの通知（F2の通知部分） | |

## 進め方
1. マイルストーンをGitHub Issueに分解する
2. Issue単位でブランチを切って実装し、テストを書く
3. 実際に触って確認してからマージする
4. 使ってみて出た不満や要望は新しいIssueにする
