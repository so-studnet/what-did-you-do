# 要件定義

「この時間に何をしていたか」「その日は何をどれくらいしたか」を振り返るための、個人用の作業記録Webアプリ。

## 前提

| 項目 | 決定内容 |
|---|---|
| 利用者 | 自分ひとり（他人の利用は想定しない） |
| 端末 | スマホとPCの両方。データは端末間で同期する |
| 形態 | レスポンシブWebアプリ + PWA（ホーム画面に追加して使える） |

## 機能要件

### F1. 作業の開始・終了（コア）
- 作業内容（タイトル）を入力して「開始」を押すと記録が始まる
- 予定時間は **任意**。指定すれば有限の作業、未指定なら無制限の作業になる
- どの作業も **いつでも終了できる**
- **複数の作業を同時に実行できる**（並行作業）
- 実行中の作業は一覧で表示し、経過時間をリアルタイムで表示する
- ブラウザを閉じたり端末を変えたりしても、実行中の状態は保たれる

### F2. 予定時間の超過（戒め機能）
- 予定時間を過ぎても **自動では終了しない**
- 超過中は見た目で分かるようにする（例：カードを警告色にし、「+12分超過」と表示）
- 予定時間に達した時点で通知を出す（PWAの通知。許可された場合のみ）
- 終了した記録にも「超過した」ことと超過時間を残す
- 集計画面で超過の回数と合計超過時間を振り返れるようにする

### F3. 記録の修正
- 終了済みの記録について、タイトル・タグ・開始時刻・終了時刻・予定時間を編集できる
- 実行中の記録の開始時刻を修正できる（開始を押し忘れた場合）
- 記録し忘れた作業を、開始・終了時刻を指定して後から追加できる
- 記録を削除できる

### F4. 階層タグ
- タグは親子関係を持てる（例：`仕事 > 会議`、`仕事 > 開発`、`趣味 > 読書`）
- 1つの作業に複数のタグを付けられる
- 集計では子タグの時間を親タグに合算して表示できる（`仕事` = `会議` + `開発` + …）
- タグの作成・名前変更・親の付け替え・削除ができる
  - 同じ階層に同じ名前のタグは作れない。自分自身や子孫を親にはできない
  - タグを削除すると、子タグは1つ上の階層に移り、記録・テンプレートからはそのタグが外れる
- タグには色を設定できる（子タグを作るときは親の色が初期値）

### F5. テンプレート
- 「タイトル + タグ + 予定時間」をテンプレートとして保存できる
- ホーム画面からテンプレートをワンタップで開始できる
- テンプレートの作成・編集・削除・並べ替えができる
- 記録の編集画面から、入力中の内容でテンプレートを作成できる

### F6. タイムライン（「この時間に何をしていたか」）
- 1日分を縦の時間軸で表示し、各作業を帯で描く
- 並行作業は横に並べて表示する
- 日付を切り替えて過去の日を見られる
- 帯をタップすると詳細表示・編集（F3）に進める

### F7. 集計（「何をどれくらいしたか」）
- 期間（日・週・月）を選んで集計する
- タグ別（階層を考慮）・作業タイトル別の合計時間を表示する
- 超過の回数と合計超過時間を表示する（F2）
- 並行作業の時間の数え方：各作業の時間をそれぞれそのまま合計する（作業の合計が実際に経過した時間を超えることがある）

## 非機能要件
- **認証**：自分だけが使えるようにログインを必須にする。新規登録は無効にする
- **時刻の正確さ**：経過時間はブラウザ内のカウンタで数えず、保存した開始時刻から計算する
- **タイムゾーン**：保存はUTC、表示は端末のタイムゾーン（基本は Asia/Tokyo）
- **日をまたぐ作業**：日ごとの表示・集計では、日の境界で分けて数える
- **操作性**：スマホでは「開始」「終了」を片手・ワンタップでできる

## 今回は対象外
- 複数ユーザー・共有機能
- オフラインでの記録（PWAにはするが、記録にはネット接続が必要）
- 外部カレンダーとの連携
